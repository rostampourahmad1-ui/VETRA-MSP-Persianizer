# VETRA MSP Persianizer

**فارسی‌ساز و بومی‌ساز Microsoft Project 2024**

## تعریف محصول

VETRA MSP Persianizer یک لایه بومی‌سازی برای Microsoft Project 2024 است که بدون جایگزین‌کردن موتور زمان‌بندی MSP، رابط کاربری، تقویم، تاریخ‌ها، Timescale، Gantt، گزارش‌ها و خروجی‌ها را با زبان فارسی، رابط راست‌به‌چپ، تقویم هجری شمسی و استانداردهای کاری پروژه‌های ایران سازگار می‌کند.

> اصل معماری: **موتور Scheduling، فایل MPP و منطق اصلی MSP باید حفظ شوند.** VETRA فقط لایه‌های فارسی‌سازی، RTL، تقویم، نمایش، گزارش و یکپارچه‌سازی را اضافه می‌کند.

## وضعیت ریپو

این ریپو در مرحله طراحی اجرایی و پیاده‌سازی هسته قرار دارد. قراردادهای معماری، نقشه‌راه، معیارهای پذیرش، هسته تبدیل تاریخ، تقویم کاری ایرانی، نگاشت ترجمه، تنظیمات نسخه‌دار و مرز Adapter اتصال به MSP ثبت شده‌اند. اتصال واقعی به MSP 2024 باید روی Windows دارای Microsoft Project اعتبارسنجی شود.

## هسته اجرایی فعلی

کد مستقل هسته در `src/vetra_core/` قرار دارد. اجرای `PYTHONPATH=src python3 -m unittest discover -s tests -p 'test_*.py'` تست‌های هسته و تنظیمات را بدون وابستگی خارجی اجرا می‌کند. این هسته زمان‌بندی را اجرا نمی‌کند؛ محاسبات برنامه‌ریزی همچنان مسئولیت Microsoft Project است.

## دامنه نسخه اول

نسخه MVP باید نصب روی MSP 2024، فارسی‌سازی UI اصلی، RTL، تبدیل و نمایش تاریخ شمسی، Date Picker شمسی، Timescale شمسی، اعداد فارسی، تعطیلات ایران و تقویم کاری ایرانی را پوشش دهد. قابلیت‌های گزارش، خروجی، Wizard، نصب‌کننده، به‌روزرسانی و تشخیص نسخه در مراحل بعدی تکمیل می‌شوند.

## اصول غیرقابل مذاکره

- VETRA نباید Scheduling Engine مستقل بسازد.
- فایل `.MPP` باید فایل اصلی باقی بماند و در MSP استاندارد باز شود.
- تبدیل تاریخ فقط در لایه ارائه و ورودی انجام می‌شود؛ تاریخ داخلی و منطق MSP نباید مخدوش شود.
- هر قابلیت جدید باید با یک سناریوی مرجع MSP و یک تست سازگاری MPP همراه باشد.
- CRM، حسابداری، قرارداد، صورت‌وضعیت، BIM، انبار، مدیریت اسناد و Workflow سازمانی خارج از دامنه این محصول هستند.
