# معیارهای پذیرش و سناریوهای آزمون

## اصل آزمون

هر سناریو باید روی یک فایل MPP مرجع در MSP 2024 اجرا شود. نتیجه محاسبات، از جمله Start، Finish، Duration، Dependency، Resource، Baseline و Critical Path، باید با اجرای مرجع انگلیسی مقایسه شود. تغییرات مجاز فقط باید در لایه ارائه، زبان، ترتیب RTL و قالب تاریخ/عدد باشند.

| شناسه | سناریو | انتظار اصلی |
|---|---|---|
| AT-01 | ایجاد پروژه با تاریخ شمسی | پروژه با تاریخ شروع معتبر ساخته و در MSP محاسبه می‌شود |
| AT-02 | تبدیل تاریخ | `۱۴۰۵/۰۶/۲۰`، `1405/06/20` و `۲۰ شهریور ۱۴۰۵` به یک تاریخ داخلی یکسان تبدیل می‌شوند |
| AT-03 | تقویم کاری ایرانی | شنبه تا چهارشنبه، پنجشنبه و جمعه مطابق تنظیم انتخابی اعمال می‌شوند |
| AT-04 | تعطیلات رسمی و سفارشی | تعطیلی رسمی و تعطیلی پروژه روی Calendar MSP اثر می‌گذارد |
| AT-05 | Date Picker | انتخاب تاریخ شمسی، اعتبارسنجی و ذخیره صحیح انجام می‌شود |
| AT-06 | RTL | فرم‌ها، Grid، منو، Tooltip و Dialog بدون بریدگی یا جابه‌جایی معنایی نمایش داده می‌شوند |
| AT-07 | Dependency | FS/SS/FF/SF و Lead/Lag در UI فارسی نمایش داده و در MSP حفظ می‌شوند |
| AT-08 | Baseline و Tracking | مقدار Baseline و Actual تغییر محاسباتی ناخواسته ندارد |
| AT-09 | MPP Compatibility | فایل ذخیره‌شده در MSP استاندارد باز می‌شود و داده‌های مرجع حفظ می‌شوند |
| AT-10 | گزارش و خروجی | PDF/Excel/Print شامل عنوان فارسی، تاریخ شمسی، RTL و فونت صحیح است |
| AT-11 | نصب و حذف | نصب‌کننده نسخه MSP را تشخیص می‌دهد و حذف، MSP و MPPها را خراب نمی‌کند |
| AT-12 | ارتقا و بازگشت | Update شکست‌خورده قابل Rollback است و تنظیمات کاربر حفظ می‌شوند |

## سطوح آزمون

تست واحد برای تبدیل تاریخ، اعداد، Parser و نگاشت ترجمه استفاده می‌شود. تست قرارداد برای Adapter و Field Mapping اجرا می‌شود. تست یکپارچه روی MSP واقعی و فایل‌های MPP مرجع انجام می‌شود. تست بصری برای RTL، فونت و Date Picker ثبت می‌شود. تست نصب روی محیط پاک و تست ارتقا روی نسخه قبلی انجام می‌شود.

## معیار رد انتشار

هرگونه تغییر ناخواسته در محاسبات MSP، خراب‌شدن فایل MPP، از دست‌رفتن داده، نقص جدی RTL، تبدیل نادرست تاریخ یا عدم امکان بازگشت نصب، انتشار را متوقف می‌کند.
